# 三张无牌阵·状态／结果

## 牌阵属性

三张从左至右摆放，共同回答一个当前状态或结果问题。没有固定的过去／现在／未来、自己／对方／关系，或现状／阻碍／建议分工。抽到牌后才依本规则判断主次，位置标签不预设主牌。

## 适用场合

用于当前处境、目前想法，或某目标能否达成等单一重点问题。“未来三个月能否复合”是结果型；带有未来期限不改变它的读法。

## 状态型三张的主次判断

| 三张牌的组成 | 主牌 |
|---|---|
| 全部大阿卡纳 | 中间牌 |
| 全部小阿卡纳 | 中间牌；宫廷牌与数字牌同级 |
| 一张大阿卡纳、两张小阿卡纳 | 唯一的大阿卡纳，不论位置 |
| 两张大阿卡纳，其中一张在中间 | 中间的大阿卡纳，不比较编号 |
| 两张大阿卡纳分列左右，中间是小阿卡纳 | 左右大阿卡纳中编号较大的一张 |

只有最后一种情况需要比较编号，采用系统所用牌组的编号约定；未提供或无法确认时，不擅自补定特殊编号。主次不由正逆位或用户喜好决定，也不等于主牌有意义、次牌可以忽略。

主牌提供核心方向，两张次牌补充表现、条件、原因或限制；先形成初步解释，再相互验证、收窄。此规则属于本课程体系，不是所有塔罗流派的统一算法。

## 解读方法与限制

整体观察 → 判定主牌 → 围绕本次问题形成核心倾向 → 用次牌补充和限制 → 回答问题。问题的对象、期限与背景从起手单理解，不从牌阵中生成。

不要用好牌多坏牌少来投票，也不要看到人物就强制对应双方。想法不能直接当作行动。没有建议位时可以提出综合分析所得的行动建议，但不能将某张重命名为建议牌。

结论应清楚、有依据，同时保留不确定性；牌面不证明现实事实，不承诺结果一定发生。
