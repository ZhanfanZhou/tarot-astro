# 前端：外壳与设计体系

React + Vite + zustand。`/showcase` 是审美基准页——拿不准的样式去那儿对。

---

## 1. Astral Atelier 设计体系

近黑底 + 古金 + 月光蓝 + 象牙白正文，衬线字体（Cinzel / Noto Serif SC），
发丝金边，充足留白。CSS 变量定义在 `src/index.css` 的 `:root`：

| 变量 | 值 | 用途 |
|---|---|---|
| `--void` / `--void-2` / `--ink` | `#06060f` / `#0a0a16` / `#04040a` | 底色、抬起的面板、最深的暗角 |
| `--gold` / `--gold-bright` / `--gold-deep` | `#c9a96e` / `#f0d090` / `#8a6d3b` | 主强调色（占卜师） |
| `--moon` / `--moon-bright` / `--moon-deep` | `#a8d8ea` / `#c9e8f5` / `#6e9db5` | 月光蓝（问卜者） |
| `--ivory` / `--ivory-dim` / `--ivory-faint` | `#ede6d6` + 两档透明 | 正文与弱化文字 |
| `--line` / `--line-soft` | 金 / 中性发丝线 | 描边 |
| `--panel` / `--panel-solid` | 磨砂面板 | 卡片、弹窗 |

**一律用变量，不写死颜色。** 动效走 framer-motion，克制：入场 stagger、cross-fade、
spring 滑入；per-deck 的 accent 只驱动细微辉光。
**全站背景** `MysticBackground`（挂在 App 最外层，殿堂、对话和所有弹层底下都是它，两端同一套）：
近黑渐变 + 两层缓慢平移的星场（CSS 动画，仍在动）+ 金 / 银蓝两团星云（`blur(60px)` + `screen` 混合）+ 一道星轨环。
星云和星轨环是**静止的**——原先的旋转和呼吸慢到看不出，却让页面每秒重画 60 帧、每帧重新模糊，手机发烫；
现在定在原呼吸区间的中间值，位置也按原先实际渲染的来（左上角贴 `left/top`，不做 translate 居中）。
常驻在屏幕上的元素，无限循环的动画哪怕慢到看不出，也会让页面停不下来，新加时要算这笔账。

## 2. 路由与外壳

```
/            App —— 殿堂（hub）与对话共用一个壳，AnimatePresence 交叉淡入
/showcase    TarotShowcase —— 牌廊 + 牌组商城 overlay
/admin       AdminApp —— React.lazy 独立 chunk，普通用户不加载
```

外壳：`TopBar`（殿堂与对话共用）+ 主区（殿堂 / 对话交叉淡入）。**没有侧栏。**

- **顶栏** `TopBar`：左 = logo + 所在之处（殿堂上是「● 殿堂 · 当前」，对话里是「‹ 殿堂」，点了回殿堂）；
  中 = 对话标题；右 = 殿堂上是钱包胸章、对话里是「⋯」（复制全部解读 / 回到最新 / 删除对话——没接着聊过的日签不出这一项）；
  最右是 `AccountMenu`（首字头像 + 名字 + 能量剩余 + 齿轮）——设置入口，点开是当前用户（含能量剩余）、转为注册用户（游客）、退出登录。
  能量剩余 = 今日额度还剩的百分比，一道细金线；窄屏（<640）名字收进面板，能量换个形状留在按钮上：
  绕着首字头像画一圈金环（底圈是金发丝线，剩多少画多少）+ 旁边一个百分数——手机顶栏被殿堂胶囊和钱包
  胸章占满，没有那条线要的 88px，环不占额外宽度。两处画的是同一个 `energy`，读数只有一份。
  什么时候刷新见 auth-and-limits.md §2。
  殿堂上顶栏透明无底线，对话里加磨砂和一条淡金底线。窄屏（<640）logo 让位，只留所在之处。
- **最近的占卜** `RecentArc`：代替侧栏的对话历史，见 §3。殿堂上放在拱窗左侧页边（窗口 ≥1400），
  对话页放在阅读列左侧页边（≥1280），当前这场停在选中线上；更窄时收成左缘一枚书签（`RecentArcEdge`）：
  一道小弧裱在暗底发丝金边的圆角框里（不写字），右侧多留一截透明内边距把可点区域撑到约 47×184，
  点开整条轨迹浮在页面上。
- 阅读列居中 `max-width: 720px`；输入坞贴底，带 `env(safe-area-inset-bottom)`。
  消息区只许上下滚（`overflow-x-hidden`，同殿堂）。气泡最宽到所在那一列为止（列 `min-w-0` + 气泡 `max-w-full`），
  放不下的内容在气泡里自己折行或截断，不把列撑出屏幕。
- **一屏就是一屏**：`#root` 宽 `100%`、高 `100dvh`（前面留一行 `100vh` 兜底），`body` 不滚动且
  `overscroll-behavior: none`。手机浏览器的 `100vh` 是「地址栏收起后」的高度，比真正看得见的一屏高一截，
  页面于是比屏幕长，一被滚动就把顶栏顶出屏幕；`dvh` 让页面永远正好等于可见区。殿堂那一层还要
  `overflow-x-hidden`——拱窗背后的背光比窗子宽一圈，不裁掉窄屏上就能左右拖动。
- **手机只适配竖屏**：横屏暂不适配（抽牌器的洗牌和扇形在横屏的矮舞台里会压到头部，已知，不处理）。
  手机端按 iPhone 13 及以后的竖屏尺寸（宽 375~430）验收。
- **手机上输入框一律 16px**（`index.css`，`<640` 时 `input / textarea / select` 强制 16px）：iPhone 上点进
  字号小于 16px 的输入框，Safari 会把整页放大且不会自己缩回，之后整页能上下左右拖、气泡看着被切掉一截、
  抽牌器也跟着页面晃。各组件自己写的字号只在桌面生效。
- **入口加载失败的兜底写在 `index.html` 里**，不在包里。`#root` 初始装一个 `#boot` 占位（「正在进入……」，
  样式内联，不依赖任何构建产物），React 首次 render 时被换掉；同一份 HTML 里还有一段内联 `<script>`，
  在入口模块之前注册捕获阶段的 `error` 监听，`<script>` 加载失败就把占位换成「页面没能加载完」＋重新加载按钮。
  必须写在 HTML 里：白屏的时候坏的正是 `main.tsx` 所在的那个产物，`ErrorBoundary` 和任何注册在包里的
  处理都不会执行。故意不加超时兜底——762KB 的入口在慢网络上本来就要等，误报比不报更糟。
  已经卡在旧缓存里、连这段新 HTML 都拿不到的老页面，由服务端的 `frontend/recovery/legacy-entry-recovery.js`
  接走：入口 JS 被新构建删掉后，那个 URL 改发这段脚本，它给当前地址加一个版本参数再整页跳转，
  逼浏览器回源取新 HTML。规则见 `deploy/nginx/frontend.conf`，发布流程见 `deploy/publish-frontend.sh`。

**殿堂（hub）自上而下**：标题 → 三扇拱窗（`SessionButtons`，网格 900 宽）→ 一排次级入口（`HubStrip`）。
在 1440×820 的窗口里三段一屏放下，更高的窗口把多出来的高度分给段间留白；更矮的就滚动，拱窗不缩。
拱窗下「进入 ›」提示挂在字下面、不占行。`HubStrip` 是一条带中心 ✦ 的金线分出三栏（窄屏竖排），不做卡片：
塔罗牌廊（小牌扇）/ 每日一签（未抽 = 呼吸牌背，已抽 = 今日牌面）/ 心灵奇旅（星座连线，游客「注册专属」不可点）。

## 3. 组件约定

- **AI 消息走 Markdown 渲染**（`react-markdown` + `remark-gfm`，自动转义、不允许裸 HTML），
  样式映射到设计体系（`h2/h3` 金色小型大写标题、`strong` 亮金、`blockquote` 金色左线…）。
  **用户消息是纯文本**，不走 markdown。
- **Composer** 是自动增高的 textarea：Enter 发送、Shift+Enter 换行，长到约 6 行后滚动。
  发出去的那句被后端以额度用完拒收（没落库）时，字回到输入框（见 auth-and-limits.md）。
- **灵感** `QuickReplies`：输入坞上面一排预设问句，「✦ 灵感」那枚开关收放。桌面默认摊开，
  手机（`<640`，与 `sm` 同一条线）默认收起——十来条要折五六行，摊开就占掉半屏对话。
  收放只做淡入淡出：动 `height` 会让换行的 flex 容器反复测量、整列对话每帧重排。
- **没有原生弹窗**：失败提示走 `useToastStore` + `<Toaster/>`，确认走 promise 形态的
  `useConfirmStore` + `ConfirmDialog`（`hideCancel` = 只留确认一个按钮，纯告知用）。代码里不应再出现 `alert` / `window.confirm`。
- **表单弹窗一套件** `components/ui/form.tsx`：登录 / 注册（`AuthModal`）、星盘资料（`AstrologyProfileModal`）、
  转为注册用户（`ConvertToRegisteredModal`）都用它，新表单也用它。
  外壳 `ModalShell` = 压暗底 + 发丝金边面板、顶上一层淡金光、右上发丝圆关闭（不传 `onClose` 就没有）；
  抬头 `ModalHeader` = 拱窗小立绘（`ui/ArchPortrait`，抽牌器头部也用它）→ 眉题 → 金色标题 → 一行说明 → 带 ✦ 的金线；
  输入框同对话输入坞（淡金发丝边，聚焦变亮晕金），下拉换成金色折角、没选时字是淡的；
  单选（性别）是 `ChoicePill`，选中 = 金边亮起 + 淡金底；主按钮 `PrimaryButton` 是暗底金边胶囊，
  次按钮 `GhostButton` 是细边胶囊，**次要在左、主要在右**。
  登录弹窗的第一屏是两扇「门」（游客 = 月牙，注册 = 连起来的星，注册那扇金边更亮、写「更好的占卜体验 · 更多使用额度」）
  + 一条「已有账号？立即登录」。
  登录弹窗只在没登录时出现，没有关闭按钮、点外面也不关，只能「返回」换一种方式；
  游客 / 注册 / 登录都等后端成功才关，失败把后端的原因写在表单上、弹窗留着。
- **最近的占卜** `RecentArc`：一段右括号形的弧线（拱高 40px），弧线不动，占卜列表沿弧滚、一次停一场。
  每一场按离「选中线」的远近沿弧往左收、变淡变小，经过选中线的那一场亮起来（点放大发光、标题变亮）。
  标题「RECENT · 最近的占卜」和搜索（只筛标题）钉在弧线起点、不参与滚动；今天 / 本周 / 更早是压在弧线上的小标签。
  条目 = 类型色点（金 = 塔罗 / 日签，蓝 = 占星）+ 标题 + 类型 · 相对时间 + 抽过牌的 `✦`，当前这场带「当前」；
  悬停出删除（没接着聊过的日签不出，规则见 [会话与解读核心](conversation-core.md) §7）。末尾一行是「共 N 场」/「没有匹配的占卜」/「还没有占卜记录」。键盘 ↑↓ 逐场、回车打开。
  时间一律按日历日算（相对时间和分组同一口径）。
- **对话里的邀请** `ChatInvite`：模型在等用户动手时（抽牌 / 补充资料）挂在那条回复末尾的按钮，
  和殿堂 `HubStrip` 的一格同一套写法——先一道带 ✦ 的金线隔开正文，再是一格：左边小图
  （抽牌 = 按牌阵张数扇开的牌背，最多三张；补资料 = 一枚小星盘），右边眉题（`THE DRAW · 3 张` /
  `BIRTH CHART`）+ 标题 + 一行说明（抽牌写出牌阵各位置），最右一枚发丝圆里的 ›。
  外面一圈发丝细框，悬停时框线亮起、背光透出、小图动一下；等着的时候小图在呼吸
  （抽牌那三张牌背的光晕是 CSS 动画 `invite-breathe`，为了抽牌器打开时能停住它）。
  抽牌金色、补资料月光蓝。桌面至少 20rem 宽、说明一行截断；手机上不设最小宽度（气泡那一列只有约 300px），
  说明折行写全，只在位置之间断行（`·` 用不断行空格贴在前一个位置上 + `break-keep`，不会把「未来」拆成两行）。
- 抽牌器 `TarotCardDrawer` 是全屏仪式组件（洗牌 + 扇形选牌）。选满之后出「确认抽牌」，点了才收场，
  单张也一样（每日一签、对话里补抽 1 张）。单张时直接点另一张就换过去；多张选满后再点别的牌不换，
  要先点已选的那张取消。
  打开即开始洗牌（没有「开始洗牌」按钮），洗完自动展扇形。**确认那一下抽牌器就退场**，
  它自己不再翻牌。整层 `touch-action: none`：弹层上的手势只给选牌器，页面不跟着拖动、缩放。
  弹层高 `85vh`，宽至少 `80rem`，窗口高的屏幕按牌桌图的宽高比（1024×577）放宽（`TABLE_ASPECT`）——只卡 80rem 的话，
  2K 显示器上弹层接近正方形，牌桌按 cover 铺满、两边被裁掉一大截；手机上仍是整屏宽。
  样子：牌桌铺满弹层、四周往底色收，离外沿 10px 一圈淡金发丝衬边；头部居中是一扇小拱窗
  （塔罗立绘，拱顶 ✦）+ 眉题（默认 `The Draw`，日签 `Daily Oracle`）+ 金色标题 + 进度
  （`凭直觉选出 N 张牌 · k / N`）；关闭是右上一枚发丝圆。槽位是一方方暗色牌位，
  位置名写在格子**上面**（选中的牌抬起来会顶进槽位这一行的下沿），格子里写罗马序号，
  下一张要落的那格亮着，选中时一张牌背落进去；扇形里选中那张头上的徽标写同一个罗马序号。
  滑轨是一道发丝金线 + 一枚 ✦ 节点。「确认抽牌」是暗底金边的胶囊，背后一团呼吸的金光。
  扇形的几何、拖动灵敏度、选牌逻辑都不在样式范围内。
  **拖动和刷手机里的列表一样**：手指按着时牌跟着手指走（1:1：手指挪正中两张牌「牌面中心」的间距
  `CARD_PITCH × 扇形缩放`，就转一张，按住的那张一直在手指底下），手指停牌就停；松手按手指离开屏幕时的速度
  接着转（inertia，时间常数 `FLING_TIME` 0.6 秒，转出去的张数 = 离手速度 × 0.6，速度上限 `MAX_SPEED` 每秒
  20 张），慢慢减速、停在整张上；转着的时候一按就停，这一按不算点牌，松手后就近落到整张。
  **滑轨是拖动条**（`beginScrub`）：整条滑轨是一整圈 78 张（旋转量 0 在正中），✦ 就在手指底下——按在 ✦ 上
  （`SLIDER_GRAB_RADIUS` 16px 内）抓住它，按在滑轨别处 ✦ 先跳到手指下；扇形跟着转，手指挪约 2.7px 转一张，
  用来快速翻到牌堆的另一段。拖到两端停在端点，松手不带惯性、就近停到整张。按住时 ✦ 放大到 1.45 倍。
  滑轨本身 8px 高，可按的范围上下各放宽 20px。
  **手势直接接 pointer 事件**（`beginGesture`：按下时在 window 上挂 move / up / cancel），不用 framer 的 `drag`。
  手指挪过 `DRAG_SLOP` 3px 才带着扇形转；挪过 `CLICK_SLOP` 8px 这一下就不算点牌——牌跟着手指走，松手时指针
  底下还是按下的那张，浏览器照样发 click，不拦就会误选；拖着牌到弹层外松手也不算「点外面关闭」。
  离手速度用事件自己的时间戳（含合并掉的 coalesced 采样和离手那一点），取最后 100ms 的平均。
  （framer 的 drag 只在动画帧里取样、按帧时间戳算速度，按下那一刻记的是它上一次跑动画那帧的时间，扇形停了几秒
  就是几秒前——快速短拨的速度被算成接近 0，松手没有惯性；它的 drag 容器还跟着手指平移，带着整片扇形每帧重画。）
  拖动元素照 framer 原先的做法关掉文字选中和 iOS 长按菜单（`GESTURE_STYLE`）。
  **扇形上一直挂着 23 个牌位**（`FanSlot`，正中左右各 11 张），转动时不增删节点：一张牌从一头转出去，
  这个牌位就绕到另一头接下一张（同手机列表复用格子）。位置、角度、大小、透明度、层级不走 React，
  `FanCards` 的 `layout` 按旋转量直接写到牌位的 style 上，挂在 framer 的帧循环里（一帧只摆一次）；
  React 只在正中那张换了时重渲染（有两个牌位换了牌：序号、选中的样子）。姿态全是旋转量的连续函数，没有延迟。
  **补牌**：一侧转出去的牌在离正中超过 11 张的那半张距离里淡出（停稳时旋转量是整数，不受影响）；另一侧补进来的牌
  从自己那个位置的正下方升上来（每个牌位一个 0→1 的 `enter` 进度，起点高度、缩放、角度、淡入同扇形展开），
  序号徽标 0.35 秒后弹出（`BADGE_DELAY`，徽标按 `badgeKey` 重新挂上）。只有落在最外两格的新牌算「补进来」：
  拖滑轨一下跳过很多张时，落在里面的牌直接换，不做动画。转得快时弹簧来不及升完，**升起最多铺到扇形上 40% 的牌**
  （`RISE_ZONE`）：新牌从入场那一侧往里走过这么多张时必须完全到位（按走过的距离算、只升不降），另一侧保持原样；
  转得慢时弹簧早就升完，不受影响。
  层级按离正中第几张排（整数），只在正中换人时写——两张牌对称地落在正中两侧时交换，不用每帧改 23 张。
  展开、补牌和选中抬起是弹簧（`spread` 一个、每个牌位一个 `enter`、每张选过的牌一个 `lift`，都是 0→1 的进度）：
  展开那一下所有牌从正中扇出去。
  不拖滑轨时 ✦ 用弹簧（stiffness 200 / damping 24）跟着旋转量走；拖滑轨时 ✦ 的显示位置（`thumbPercent`）
  直接设成手指处、不经过弹簧，松手时弹簧从那里接上。不能逐个手指事件把弹簧 jump 过去：framer 按相邻两次更新
  算弹簧速度、默认一帧一次，手指事件一帧好几个、间隔不到 1ms，算出的速度会把 ✦ 甩飞；
  `translateX` 定位（改 `left` 每帧都要重新布局）。
  一按下（以及惯性期间，停下后再留 0.8 秒）每张牌单独一层（`will-change: transform`），移动只做合成、不重画整个扇形；
  静止时撤掉，否则放大的牌会按放大前的尺寸栅格化、发虚。选中那张的呼吸金光是两层固定光晕交替淡入淡出
  （`index.css` 的 `fan-glow-*`，只动透明度）——逐帧改 box-shadow 的话，选中之后什么都不动这一片也每帧重画。
  **牌底下一道扇形的暖光**（`FAN_GLOW_STYLE`）：和扇形同心的椭圆径向渐变，贴着牌的底边最亮（不透明度 0.21），
  往扇形里面渐暗，两头用 conic 蒙版按扇形张角收掉。不跟着转、不用 blur 滤镜，转牌时不重画。
  **打开期间底下的装饰动画停住**：抽牌器给 `<html>` 挂 `data-drawer-open`，星空平移和对话里邀请小图的呼吸
  （`index.css` 的规则）停在当前那一帧——弹层 95% 黑，它们本来看不见，却让整页每帧重画。
- 揭牌是抽牌之后的另一幕 `CardRevealOverlay`：不再是全黑弹层，而是半透明压暗一层
  （`rgba(6,6,15,0.62)` + 轻微模糊）盖在对话界面上，后面的对话仍看得见。牌背先按牌阵落位，
  真牌从后端回来后逐张翻开——3D `rotateY` 翻面 + 抬起前移 + 翻到一半炸开的光晕 + 扫过牌面的高光，
  牌名和正逆位在翻过来之后浮出来。翻完停一拍自己淡出，这时牌已经画在对话里了；点一下可跳过。
  真牌由服务端定，所以 `cards` 允许先是 `null`（等牌阶段只摆牌背）。
  **两种排法**：默认一排摆开；窄屏（`max-width: 639px`，与 `sm` 同一条线）的 2~3 张牌阵改成
  **一张一张切换**——并排只剩指甲盖大，所以一次一张大牌，左右滑动换牌、底下一排进度点。
  窄屏单张或 4 张以上仍是一排（牌宽按 `vw` 收小，多的自动换行）。
  牌距不是定值，而是 `牌宽 × 系数`，系数按张数分档（≤3 张 0.34、4~6 张 0.24、更多 0.16）：
  牌少摊得开，牌多仍在一行里放得下。
  右上角常驻一个**跳过**按钮（牌一开翻就出现），手机上不必靠「点任意处」猜。
- 牌面大图 `CardPreview`（灯箱）：对话里的牌、每日一签舞台上的牌，点一下都开这一个。原图一律正着放，
  逆位牌也不倒过来（牌名旁另标「逆位」）；带中英文牌名，点空白或 × 关。手机、电脑一样。
- 洗牌花式在 `components/shufflePatterns.ts`：**同一个动作**（牌飞出去、转一圈、落回叠上）
  的三套参数，不是三套编舞——区别只在往哪散、旋向齐不齐、抬升什么形状、错开多久；
  刻意没给它们起名字，只有 0/1/2。每次抽牌随机取一种，整段 3~4.2 秒、比原版短约 15%（时长和错开都带随机，同一花式每次不完全一样）。
  性能红线写在文件头：同时 ≤ 20 张牌，只动 transform 与 opacity，关键帧开洗时算一次。
- 本地调动画用 `/lab/shuffle` 预览页（选牌阵、指定花式、反复重洗，全程不连后端）：
  顺序和线上一致，洗牌 → 选牌 → 确认之后接着演揭牌，另有「只重放揭牌」单看翻牌那一段。
  那个页面**不进 git**，`main.tsx` 用 `import.meta.glob` 挂它的路由，文件不在时自动没这条路由。

## 4. 状态

| store | 管什么 |
|---|---|
| `useAuthStore` | 当前用户 + token（持久化 localStorage） |
| `useConversationStore` | 当前会话、会话列表、进行中的那一轮 |
| `useDeckWallet` | 钱包（余额 / 已拥有 / 当前牌组），**后端为唯一来源** |
| `useToastStore` · `useConfirmStore` | 提示与确认 |

**界面状态不另存**：要不要显示抽牌 / 补资料按钮、抽牌器用什么牌阵，
都从当前会话末尾那条 assistant 的 `tool_calls` 推导（见 [会话与解读核心](conversation-core.md) §4）。

## 5. 接口层

`services/api.ts` 一处封装：axios 实例 + 拦截器（带 token、401 登出）+ SSE 解析。
SSE 端点用原生 `fetch`，手动拼 `Authorization`。
管理端另有 `services/adminApi.ts`，独立实例、独立 token。
